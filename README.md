# 🤖 AI Social Media Content Generator

A professional AI-powered web application that helps users generate creative social media content quickly and efficiently.

## 📌 About The Project

The AI Social Media Content Generator is designed to help individuals, content creators, and businesses generate engaging social media content.

Users can provide their requirements, and the application generates useful content ideas, captions, and hashtags using Artificial Intelligence.

## ✨ Features

* 💡 Generate creative social media post ideas
* ✍️ Generate engaging captions
* #️⃣ Generate relevant hashtags
* 🤖 AI-powered content generation
* 📱 Simple and user-friendly interface
* ⚡ Fast content generation

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* Anthropic Claude AI API

## 🚀 How It Works

1. The user enters their content requirements.
2. The request is sent to the backend server.
3. The AI processes the request.
4. Generated social media content is displayed to the user.

## 💻 Installation

### Clone the repository

```bash
git clone https://github.com/rahabali2204-web/social-media-generator.git
```

### Open the project folder

```bash
cd social-media-generator
```

### Install dependencies

```bash
npm run install-all
```

### Add your API Key

Create a `.env` file inside the `server` folder and add your Anthropic API key:

```env
ANTHROPIC_API_KEY=your_api_key_here
```

### Run the project

```bash
npm run dev
```

Then open the application in your browser.
